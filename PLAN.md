# TripBoard — план

Один шаг за раз. Логику и архитектуру сначала обсуждаем, потом пишет Юрий. Базовые стили, кнопки, поля и сетку форм ассистент делает сразу, без отдельной просьбы. Проверка — в чате.

## Решения

- React + TypeScript + Vite
- Стили: SCSS (`sass` стоит, Vite собирает `.scss` сам)
- Данные на этапе 1: `localStorage`
- Redux не используем. Общее состояние — средствами React, подключим, когда появится список поездок
- React Router — когда появится второй экран
- Этап 2 (backend, парсинг CFR, пост в Telegram) не делаем
